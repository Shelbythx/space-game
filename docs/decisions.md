## Відкриті питання

| Питання | Варіанти / нотатки |
| --- | --- |
| Концепція гри й цільова аудиторія | Не обговорювалось |
| Стек бекенду й фронтенду | Мови та фреймворки не обрано |
| Хто робить бекенд, хто фронтенд | Невідомо |
| Межа між бекендом і фронтендом | Де живе логіка симуляції та стан гри; агент пропонує: на бекенді, фронтенд лише показує. Не підтверджено |
| Контракт API | Агент пропонує узгодити його першою задачею в `docs/api.md` до початку розробки обох частин. Не підтверджено |
| Командний режим (до 4 гравців) | Hot-seat на одному екрані чи мережевий; чи робити взагалі в MVP |
| Обсяг MVP | Чернетка агента є в `challenge-context.md`; не підтверджено |
| Склад команди й ролі | Невідомо |
| Ролі гравців у командному режимі | Агент пропонує взяти чотири сегменти місії з матеріалів NASA (запуск, апарат, наземний, науковці). Не підтверджено |
| Локація події та локальний дедлайн | Невідомо |
| Музика гри | Треки з Murder Drones — лише референс настрою; чим їх замінити, не вирішено |
| Ліцензія репозиторію | Залежить від правил Space Apps — не перевірено |
| Злиття в `main` | Через pull request чи прямим злиттям; чи потрібен рев'ю |
| Формат задач | Агент завів файли в `tasks/`; альтернатива — GitHub Issues. Не підтверджено |
| Гілка `main` | Ще не існує: у репозиторії лише `claude/vibrant-ritchie-tm2d9g` |
