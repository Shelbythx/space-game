# Ресурси челенджу (вкладка Resources)

Отримано від користувача 14.11.2026 текстом з офіційної сторінки. Самі посилання з
хмарних сесій не відкривались — опис кожного ресурсу взято зі сторінки челенджу, а
колонка «Що це дає грі» — висновки агента, не перевірені за першоджерелом.

## Головні висновки

1. **Датасетів немає.** Ресурси — це методики, інструменти та приклади ігор. Каталог
   компонентів, інструментів, орбіт і носіїв із числами команда складає сама; CubeSat 101
   і GMAT допоможуть тримати цифри правдоподібними.
2. **Чотири сегменти місії ↔ чотири гравці.** Запуск, космічний апарат, наземний сегмент
   і користувачі-науковці — готовий розподіл ролей для командного режиму, взятий прямо з
   матеріалів NASA.
3. **Етапи CML та MDL — готова структура гри:** ідея → здійсненність → порівняння
   варіантів → детальний проєкт → симуляція.
4. **Гра про Webb — планка, яку треба перевершити.** Вона вже робить «цілі → інструменти →
   запуск → результат», але без ресурсів, бюджету, командної гри та пояснення причин
   невдачі. Саме цього просить челендж.
5. **Наземний і користувацький сегменти** в офіційному тексті челенджу майже не згадані,
   але є в ресурсах — це простір для оригінальної механіки (наземні станції, вікна
   зв'язку, цінність даних для науковців).
