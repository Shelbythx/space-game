# Контекст челенджу: Space Mission Design Game

Зібрано 14.11.2026. Хакатон: **NASA Space Apps Challenge 2026**, 14–15 листопада 2026.

> **Важливо.** Офіційну сторінку челенджу та вкладку **Resources** з цього середовища
> прочитати не вдалося (див. розділ «Чого бракує»). Усе нижче — з вторинних джерел
> (пост NASA, сторінки локальних подій, пошукові зведення). Перед тим як покладатися на
> формулювання, звірте їх з офіційною сторінкою.

## Суть челенджу

Офіційне формулювання (пост Learn With NASA):

> Create an interactive game where participants design, manage & simulate a complete
> space mission while making engineering decisions, managing limited resources &
> evaluating how each choice shapes mission success.

- Рівень складності: Beginner / Youth та Intermediate.
- Гравець має балансувати конкуруючі вимоги: цілі місії, конструкція апарата,
  наукові інструменти, ракета-носій, бюджет, енергія, маса, зв'язок, орбітальні
  обмеження.
- Ключова механіка — **обмежені ресурси й компроміси**: кожне рішення має видимо
  впливати на успіх місії.
- Гра має покривати місію **від початку до кінця** (проєктування → запуск → операції →
  результат), а не лише конструктор апарата.

## Дедлайни та подача

- Подача проєктів: відкривається в суботу 14.11 о 9:00, закривається в неділю 15.11
  о **23:59 за місцевим часом**.
- Локальні події можуть мати власний, раніший дедлайн для локального суддівства —
  уточнити в організаторів нашої локації.
- Щоб потрапити на Global Judging, команда має обрати челендж і подати проєкт у межах
  хакатону.

## Критерії оцінювання

За вторинними джерелами — п'ять критеріїв (офіційні формулювання й ваги не
підтверджені):

| Критерій | Що це означає для гри |
| --- | --- |
| Impact | Чи вчить гра реальних компромісів проєктування місій; хто аудиторія |
| Creativity | Свіжа механіка чи подача, а не ще один «конструктор ракети» |
| Validity | Правдоподібні цифри й залежності (маса, енергія, delta-v, бюджет, зв'язок) |
| Relevance | Чи відповідає проєкт саме цьому челенджу: повна місія, ресурси, наслідки рішень |
| Presentation | Чітке демо та пояснення проєкту на сторінці подачі |

## Що вже роблять інші команди

Публічні репозиторії цього ж челенджу (для орієнтиру, не як джерело вимог):

- React + Vite гра з бюджетами маси, енергії, зв'язку та орбітальними компромісами.
- Піксель-арт гра «спроєктуй апарат і запусти».
- Варіант на 1–4 гравців із бюджетами mass / power / budget / data / comms / time.

Типовий набір ресурсів у всіх — гроші, маса, енергія, дані/зв'язок, час. Щоб виділитися
за Creativity, варто шукати власний кут (наприклад, сценарії відмов під час польоту,
кооператив із ролями, реальні місії як рівні).

## Чого бракує

1. **Вкладка Resources офіційної сторінки** — перелік матеріалів і датасетів NASA та
   партнерів. Не отримано.
2. Точні розділи Objectives / Potential Considerations з офіційної сторінки.
3. Офіційні формулювання критеріїв оцінювання та правила щодо використання ШІ
   (у Space Apps зазвичай вимагають зазначати використання ШІ у подачі — перевірити).
4. Вимоги до ліцензії та відкритості коду.

Причина: сервер `www.spaceappschallenge.org` віддає ланцюжок сертифікатів, який не
проходить перевірку TLS у цьому хмарному середовищі, а вимикати перевірку не можна.
Найпростіше — відкрити сторінку в браузері й зберегти текст вкладок Details та
Resources у `docs/` (наприклад, `docs/official-challenge.md`).

## Відкриті рішення для команди

- Платформа та стек (браузерна гра найпростіша для демо суддям).
- Концепція та аудиторія (школярі / студенти / широка публіка).
- Обсяг MVP на 48 годин і розподіл ролей.
- Ліцензія репозиторію.
