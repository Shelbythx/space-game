## Мета

Оновити контракт під D78–D85: три місії, двигун, пам'ять, МКС, траса, DONKI, схожа місія. Перелік змін — `docs/development-plan.md`, розділ 5.

## Обсяг

- `docs/api.md`: усі зміни з розділу 5 плану, приклади JSON для кожної нової частини.
- `docs/openapi.yaml`: той самий контракт.
- Нові коди повідомлень (перевірки, коментарі, ланцюжки, події) — перелік у `docs/api.md`.
- Не входить: код бекенду й фронтенду.

## Зона файлів

- `docs/api.md`, `docs/openapi.yaml`

## Критерії готовності

- [x] Кожне поле з розділу 5 плану описано з одиницею в назві.
- [ ] `openapi.yaml` проходить валідацію (наприклад, `npx @redocly/cli lint`). Локально
  перевірено лише структуру (усі 98 `$ref` ведуть на наявні схеми, дужки збалансовані);
  запуск `npx @redocly/cli lint` заблокувала система дозволів агента — треба прогнати.

## Нотатки

- Відхилення від розділу 5 плану: `lat`, `lon` у `groundTrack` названо `latDeg`, `lonDeg`
  (одиниця в назві). План (`development-plan.md`, поза зоною) варто виправити.
- Додано понад розділ 5 — без цього не працюють задачі 010, 024, 004: `longitudeDeg` у
  станцій (сеанси D79 і зони на карті), `specs.band` у радіо (D80), `specs.dragAreaM2` у
  корпусу (гальмування, 2.8), `Orbit.epochDate` (дата файлу OEM МКС), `resources.cargo`
  і `goal` для `iss`, покроковий `rendezvous` у `simulate`, `contacts[].visibilityRadiusDeg`,
  подія `reentry`, `Comparison.source`, `LaunchSite`, `CargoCategory`.
- Ідентифікатори каталогів (`Orbit.id`, `Launch.id`, `Instrument.id`, `GroundStation.id`)
  в OpenAPI тепер відкриті рядки замість `enum`, щоб 017–019 додавали їх без зміни контракту.
- Ламаючі зміни для фронтенду: `scores` — об'єкти `{ value, formula }`; сьома обов'язкова
  категорія `propulsion`. `frontend/src/api/types.ts` (поза зоною) треба оновити в 008.
- Ціль місії `iss` (`cargoKg`, `scienceCargoMinPct`, `dockingDeadlineDays`) і поля деталей
  корабля — заглушки до 017; якщо 017 вирішить інакше — окрема зміна контракту.
- Прибрано застарілі згадки GitHub Pages і Render (D77) у CORS і `/api/health`.
