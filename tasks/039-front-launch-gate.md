## Критерії готовності

- [x] Нова гра бере корпус і деталі з набору, але без корисного навантаження: станції (або
  ретранслятор) обирає планувальник, прилади чи вантаж — науковець. Без них бекенд провалює
  перевірки (`check.ground.noStation`, `check.user.goalMissed` / `check.user.cargoShort`).
- [x] «Старт місії» активна лише тоді, коли свіжа оцінка саме цього проєкту не має провалених
  перевірок (ризики дозволені). Стара оцінка під час перерахунку не відкриває старт.
- [x] Політ і звіт відкриті лише для проєкту, з яким натиснули «Старт місії» (`smdg.launch.<місія>`
  у localStorage). Зміна проєкту після старту знову закриває їх із поясненням; «Новий політ» у
  звіті — той самий проєкт, тож не закриває.
- [x] У плані польоту закриті етапи — не посилання; пряма адреса показує пояснення й кнопку до
  «Проєкту». «Нова гра» скидає старт.
- [x] Перевірено в Browser pane з локальним бекендом: свіжий старт → звіт і політ закриті, кнопка
  неактивна (2 провалені перевірки) → станції + камера → старт → політ → звіт «Місія вдалася» →
  перезавантаження (звіт відкритий) → зміна приладу → звіт закритий. 375 px — без горизонтального скролу.
