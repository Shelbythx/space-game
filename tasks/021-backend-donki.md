## Мета

Справжні магнітні бурі NASA в польоті (D83) з дотриманням детермінізму (D65).

## Обсяг

- Модуль `SpaceWeather`: клієнт `https://api.nasa.gov/DONKI/GST`, ключ зі змінної `NASA_API_KEY` (за замовчуванням `DEMO_KEY`).
- Seed → історичний 12-місячний період у межах 2010–2025; бурі з Kp → дні місії.
- Кеш у таблиці `space_weather_cache`; API недоступний → кеш; нема кешу → подія `spaceWeatherUnavailable`.
- Публічний інтерфейс для `Simulation`: бурі за періодом.
- Тести з записаною відповіддю API (без мережі).

## Зона файлів

- `backend/src/**/SpaceWeather/`, міграція таблиці кешу

## Критерії готовності

- [ ] Той самий seed дає ті самі бурі (тест).
- [ ] Без мережі симуляція не падає.
