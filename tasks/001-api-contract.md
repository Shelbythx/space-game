## Мета

Описати в `docs/api.md` усі точки API між бекендом і фронтендом (D60), щоб обидві
частини будувались під один контракт.

## Обсяг

- Точки: `health`, місії, `evaluate`, `simulate`, `attempts`.
- Схеми проєкту місії, ресурсів, перевірок, коментарів ролей, звіту.
- Коди повідомлень, одиниці, помилки, CORS.
- Не входить: код бекенду чи фронтенду.

## Зона файлів

- `docs/api.md`

## Критерії готовності

- [x] Кожна точка має запит, відповідь і приклад JSON.
- [x] Схеми покривають шість ресурсів, чотири сегменти, чотири ролі, обидві версії SINGLE.
- [x] Описано, як фронтенд перекладає коди повідомлень.
