## Мета

Дані для «схожої місії» у звіті (D85): реальні місії NASA та заздалегідь змодельовані еталонні.

## Обсяг

- 8–12 реальних місій (минулі, діючі, заплановані): наприклад Landsat 9, Aqua, GOES, TDRS, CubeSat-місії, вантажні місії CRS. Орбіта, маса, інструменти, обсяг даних, джерело (NSSDCA, сторінка місії).
- 4–6 змодельованих еталонних проєктів для кожної місії гри (дешевий, збалансований, найкращий…) — записані як `Design` для прорахунку нашою симуляцією.
- Новий файл `docs/reference-missions.md`.
